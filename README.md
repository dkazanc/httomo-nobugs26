# HTTomo presentation material

HTTomo slides using [quarto-revealjs](https://quarto.org/docs/presentations/revealjs/) presentation format for hands-on meetings and also general [HTTomo software](https://github.com/DiamondLightSource/HTTomo) overview.

## Useful links:

- [HTTomo Github page](https://github.com/DiamondLightSource/HTTomo)
- [HTTomo Documentation](https://diamondlightsource.github.io/httomo/)

### How to html-render those slides

1. Install [Quarto](https://quarto.org/docs/get-started/)
2. git clone the repo
3. quarto preview # render into a preview
4. quarto publish gh-pages # publish pages
